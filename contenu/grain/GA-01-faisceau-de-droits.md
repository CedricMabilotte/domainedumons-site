# GA-01 — Le faisceau de droits, un gabarit vierge

*Décrire le rapport d'un collectif à chacune de ses ressources par cinq droits distincts, plutôt que par la propriété. Le tableau vide, à copier tel quel, et les trois pièges qu'il évite.*

---

## Pourquoi un faisceau plutôt qu'un schéma de propriété

Dire « le fonds est nu-propriétaire, l'association a l'usage » décrit un montage juridique. Ça ne dit pas qui peut entrer, qui peut couper un arbre, qui décide d'ouvrir une parcelle au public, ni ce qui se passe quand quelqu'un part. **Ces questions-là ne se lisent pas dans un régime de propriété ; elles se lisent dans un faisceau.**

Elinor Ostrom et Edella Schlager ont montré en 1992 qu'un rapport à une ressource commune se décrit par **cinq droits distincts**, qui ne vont pas ensemble et se répartissent entre des mains différentes. C'est ce qui permet de dire, sans contradiction, qu'une terre n'appartient à personne et que tout le monde n'y fait pas n'importe quoi.

## Les cinq droits, définis

Les définitions comptent : deux personnes qui n'appellent pas « gestion » la même chose ne peuvent pas se mettre d'accord sur qui l'exerce.

| Droit | Ce qu'il permet | La question qui le révèle |
|---|---|---|
| **Accès** | Entrer, être là, jouir de ce qui ne se consomme pas — traverser, regarder, se reposer | *Qui peut venir sans demander ?* |
| **Prélèvement** | Prendre des unités de la ressource — récolter, couper, puiser, pâturer | *Qui peut emporter quelque chose ?* |
| **Gestion** | Transformer la ressource et régler son usage interne — planter, construire, drainer, fixer les règles de prélèvement | *Qui décide de ce qu'on fait du lieu ?* |
| **Exclusion** | Décider qui détient l'accès et le prélèvement, et comment ces droits se transmettent | *Qui décide qui entre ?* |
| **Aliénation** | Vendre ou céder les droits de gestion et d'exclusion | *Qui peut faire sortir la ressource du dispositif ?* |

**Les quatre positions qui en découlent**, dans l'ordre croissant :

- **Utilisateur autorisé** — accès + prélèvement
- **Revendicateur** — + gestion
- **Détenteur** — + exclusion
- **Propriétaire** — + aliénation

Un projet de sortie du marché tient en une phrase : faire que **personne n'occupe la position de propriétaire**, et que le droit d'aliénation soit non pas détenu mais **structurellement empêché** — voir [[PA-01-verrou-structurel]].

## Le gabarit vierge

À copier tel quel. Une ressource par tableau ; une colonne par ayant droit ; un statut par cellule, jamais une case vide — **« on n'y a pas pensé » est une réponse, et elle se distingue de « pas encore tranché »**.

```
RESSOURCE : ...........................

| Droit        | ..... | ..... | ..... | ..... | Statut | Par quel acte ? |
|--------------|-------|-------|-------|-------|--------|-----------------|
| Accès        |       |       |       |       |        |                 |
| Prélèvement  |       |       |       |       |        |                 |
| Gestion      |       |       |       |       |        |                 |
| Exclusion    |       |       |       |       |        |                 |
| Aliénation   |       |       |       |       |        |                 |

Statuts : ACTÉ (acte signé, décision datée) · PROPOSÉ (soumis, en attente)
          EXPLORÉ (piste) · NON TRANCHÉ (identifié, pas instruit)
          NON POSÉ (personne n'y a encore pensé)
```

**La colonne « par quel acte ? » est celle qui fait le travail.** Un droit sans instrument est une intention. Si la colonne est vide, la cellule n'est pas `ACTÉ`, quoi qu'en dise la première.

**Trois questions à se poser avant de remplir**, dans cet ordre :

1. **Qui exerce ce droit aujourd'hui, en fait ?** Pas qui devrait. Le tableau des faits avant le tableau des titres.
2. **Que se passe-t-il quand cette personne part ?** C'est le test qui sépare un droit personnel d'un droit réel.
3. **Qui peut retirer ce droit, et comment ?** S'il n'y a pas de réponse, le droit n'est pas encadré — il est seulement toléré.

**Ressources à ne pas oublier**, parce qu'elles reviennent partout et qu'on ne les liste presque jamais : les outils apportés par les personnes · l'eau · le nom et l'image · les données · et **le travail lui-même** — qui décide de ce qui doit être fait, et qui décide que c'est fait.

## Trois pièges

**Confondre gestion et prélèvement.** Ramasser du bois mort et abattre une haie ne sont pas le même droit, même s'ils produisent tous deux du bois. Le second modifie la ressource pour les suivants. Un collectif qui délègue les deux au même niveau se réveille avec un versant ouvert.

**Croire que l'aliénation se supprime.** Elle ne se supprime pas, elle se répartit et se verrouille. Un droit que personne ne détient est un droit que le premier juge saisi réattribuera. Le verrou doit être **structurel**, pas contractuel.

**Remplir le tableau au présent quand on décrit un projet.** La tentation est d'écrire ce que le montage fera, et de le lire six mois plus tard comme ce qu'il fait. D'où le statut par cellule.
