# Domaine du Mons — données ouvertes d'un lieu collectif (Vitrac-sur-Montane, Corrèze)

Données d'un lieu collectif expérimental : climat, associations, carte, bilans annuels (JSON/CSV, Licence Ouverte 2.0), textes et fiches du Grain ; site comons.actitude.org.

## Réutiliser

- **Fiches** : `data/*.json` et `data/*.csv` (climat, associations, carte, bilans ; détail champ par champ dans `data/LISEZMOI.md`), textes dans `contenu/`. Adresse stable sur le site : https://comons.actitude.org/ (pages HTML à la racine ; données : `https://comons.actitude.org/data/<fichier>`).
- **Téléchargement** : chaque fichier de `data/` est téléchargeable à son adresse.
- **Licences** (`LICENSE`) : textes CC BY-NC-SA 4.0 ; données Licence Ouverte 2.0 ; code AGPL-3.0-or-later ; sources tierces à leur licence.
- **Citer** : `CITATION.cff` (GitHub : « Cite this repository »). Archive pérenne : Software Heritage,
  https://archive.softwareheritage.org/browse/origin/?origin_url=https://github.com/CedricMabilotte/domainedumons-site
- **Corriger** : `CONTRIBUTING.md` — une issue ou une PR par fiche, source citée, réponse sous un mois.
