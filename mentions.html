Éditeur

Le collectif expérimental du Domaine du Mons, à Vitrac-sur-Montane (Corrèze). L'association qui portera le site est en cours de constitution ; d'ici là, le site est tenu par un membre du collectif. Contact : contact@actitude.org.

Hébergeur

GitHub Pages, service de GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, États-Unis. Le code et les données du site sont dans un dépôt public : CedricMabilotte/domainedumons-site.

Une réserve

GitHub est une plateforme propriétaire. Nous l'utilisons parce qu'elle ne coûte rien et publie un dépôt ouvert tel quel. Le site est fait de fichiers statiques : il se redéploie ailleurs sans réécriture le jour où nous le déciderons.

Données personnelles

Ce site n'utilise aucun traceur, aucun cookie, aucune mesure d'audience, et n'enregistre rien sur votre appareil. Les polices sont celles de votre système. Les tableaux de bord interrogent directement, depuis votre navigateur, Hub'Eau, VigiEau et Open-Meteo ; ces services reçoivent donc votre adresse IP, comme toute page web qu'on consulte. L'hébergeur peut journaliser les connexions selon sa propre politique ; nous n'avons pas accès à ces journaux.

Les liens « Relayer » vers Telegram, Facebook ou votre instance Mastodon sont des liens ordinaires : ces services ne reçoivent rien tant que vous ne cliquez pas. Le nom d'instance que vous tapez pour Mastodon n'est ni envoyé ni conservé.

Si vous nous écrivez, votre message et votre adresse servent à vous répondre et à rien d'autre. Vous pouvez demander leur effacement à tout moment.

Droit de réponse

Les pages du réseau republient des informations publiques sur d'autres lieux et d'autres associations. Correction ou retrait sur simple demande à contact@actitude.org : le retrait est fait sans discussion et sans délai, la correction est datée dans le journal des versions de la page concernée.
